# CONTRIBUTING

用于记录项目协作流程、开发约定、测试要求和提交规范。

## 协作流程

- 所有 agent 开始工作前，应先阅读 `../AGENTS.md`、`_agent/WRITE_RULES.md` 和与任务相关的 `_agent` 文档。
- 开始实施前，应检查任务相关代码、数据结构和当前 git 状态，并向用户说明影响范围。
- 实施过程中，应保持改动范围清晰，避免无关重构和无法追溯的混合变更。
- 实施后，应说明已完成内容、未完成内容、验证状态和后续建议。
- 破坏性操作、大范围重构、外部联网、写入 `_agent` 或修改 `AGENTS.md` 前，必须先得到用户明确确认。
