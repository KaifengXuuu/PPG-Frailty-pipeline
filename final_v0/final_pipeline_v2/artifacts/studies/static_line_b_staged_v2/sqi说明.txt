旧版：


当前 SQI 是一个自定义、无监督、window-level 质量评分，不是每个采样点一个 SQI。
输入单位：一个完整 window，例如 5 秒 × 400 Hz = 2000 samples。
输出单位：每个 window 一个无量纲分数，归一化到 [0,1]。
gating 单位：按 window 排名和保留。
top70_quality/top50_quality 不是 SQI >= 0.7/0.5，而是保留每组排名最高的 70%/50% windows。



SQI 接收已经完成以下处理的 [N,8,T] windows：
PPG interpolation、detrend、0.2–8 Hz bandpass。
accelerometer low-pass 和 gravity removal。
gyroscope low-pass。
切成 window。
每个 window、每个通道执行 median/IQR 标准化，并 clip 到 [-8,8]。
因此 SQI 看到的不是原始物理幅度，而是标准化后的相对波形。尤其 IMU 已不再具有原始 g 或角速度单位。


| 分量 | 权重 | 算法 | 含义 |
|---|---:|---|---|
| `spectral_ratio` | 0.40 | 0.5–3 Hz 功率 / 总功率 | 心率频段能量集中度 |
| `ppi_stability` | 0.35 | `1/(1+std(PPI)/mean(PPI))` | 峰间距稳定性 |
| `peak_density` | 0.15 | 峰数 / 理论最大峰数 | 是否存在足够脉搏峰 |
| `motion_penalty` | 0.10 | IMU RMS 运动惩罚 | 抑制运动较强的 window |

SQI_raw =
    0.40 × spectral_ratio
  + 0.35 × ppi_stability
  + 0.15 × peak_density
  + 0.10 × motion_penalty

频谱阈值Welch PSD 使用：
nperseg = min(512, window_samples)
PPG band = 0.5–3.0 Hz
0.5–3 Hz 大致对应 30–180 bpm。spectral_ratio 越接近 1，表示 PPG 能量越集中在合理心率频段。

峰值阈值：
minimum peak distance = 0.28 × fs
prominence = 0.3

400 Hz 下 minimum distance 是 112 samples，即约 0.28 秒，对应约 214 bpm 的峰值上限。
少于 3 个峰时：ppi_stability = 0
                       peak_density = 0

峰数达到 3 后，PPI stability 实际是峰间距的 coefficient of variation 的反函数。间距完全稳定时接近 1，越不规则越接近 0。
peak_density 使用：min(1, number_of_peaks / (window_seconds × 3))

Motion threshold：
motion = RMS(norm(acc)) + 0.25 × RMS(norm(gyro))
motion_penalty = 1 / (1 + max(0, motion - 1))
但这里的 1 是标准化后 IMU 的无量纲阈值，不是 1 g。由于每个 IMU 轴已独立标准化，它更接近“相对波动惩罚”，不能解释成真实运动强度。

SQI 归一化：
所有 windows 得到 SQI_raw 后，以整个输入 window table 的第 5、95 百分位缩放：
SQI = clip((SQI_raw - P5) / (P95 - P5), 0, 1)

Top70/Top50 Gating
top70_quality: 保留 ceil(window_count × 0.70)
top50_quality: 保留 ceil(window_count × 0.50)
至少保留 1 个 window
没有绝对 SQI threshold。即使某个文件所有 windows 都很差，仍会保留最高的 50%/70%；反过来，即使全部很好，也会删除剩余 30%/50%。



不同阶段的分组单位：
| 环节 | SQI grouping | 处理 |
|---|---|---|
| 训练集 | 每个 file | 删除该文件低排名 windows |
| validation window 指标 | 不 gating | 所有 validation windows 都计算指标 |
| file-level aggregation | 每个 file | 只聚合该文件 Top 70%/50% |
| subject-level aggregation | 每个 subject | 在该 subject 全部 windows 中选 Top 70%/50% |


Aggregation：
筛选后的概率有两种聚合：
mean_prob：所有选中 windows 等权平均。
quality_weighted_mean：按 SQI 分数加权平均；总权重接近零时回退到普通平均。
stage1 同时试验 none/top70/top50 和两种 aggregation；generalization sweep 只使用 none/top50，aggregation 固定为 mean_prob。



评价：
当前 SQI 的价值是提供 label-independent 的 window quality ranking，但它不是经过 ECG/人工质量标签验证的标准 SQI。主要问题是：
峰值检测不是 Aboy++。
PPG 和 IMU 在 SQI 前已经 per-window 标准化，绝对振幅和真实运动单位丢失。
top50/top70 是固定保留比例，不是经过验证的质量阈值。
SQI 的 P5/P95 使用全部 windows 计算。
训练、file aggregation、subject aggregation 的 grouping 单位不同。
