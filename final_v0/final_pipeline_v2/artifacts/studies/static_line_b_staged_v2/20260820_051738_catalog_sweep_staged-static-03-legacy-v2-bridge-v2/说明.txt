八、详细解释三行转换
1. exhaustive shuffle → uniform replacement
Exhaustive shuffle

假设训练集有 N=10,000 个 windows。

普通：

DataLoader(shuffle=True)

每个 epoch：

10,000 个 windows 全部出现一次；
没有重复；
没有遗漏；
只改变出现顺序。
Uniform replacement

改为：

WeightedRandomSampler(
    weights=np.ones(N),
    num_samples=N,
    replacement=True,
)

每次抽取后不把该 window 从候选池删除。

因此一个 epoch 中：

有些 windows 出现两次、三次或更多；
有些 windows一次都没有出现；
总抽样次数仍是 N。

当 N 较大时，一个 epoch 中期望出现的不同 windows 数约为：

Line B sampler

将概率改成：

P(i)=P(participant)P(role family∣participant)P(file∣family)P(window∣file).

结果是：

每名 participant 总概率相同；
B/R family 各占一半；
R1–R4 在 R family 内平分；
file windows 越多，每条 window 的单独概率越低。

然后 class-weighted cross-entropy 再放大 participant 人数较少类别的 loss。

因此这一步同时改变：

batch 中看见哪些 windows；
B 与 recovery 的比例；
每个 participant 的贡献；
每个 class error 的 loss 大小。
