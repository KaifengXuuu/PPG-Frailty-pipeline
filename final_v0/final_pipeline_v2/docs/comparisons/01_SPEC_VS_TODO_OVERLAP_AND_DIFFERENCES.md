# V2 specification and deferred-decision boundary

The DEV0 specification is frozen by byte hash, but explicit V2 human decisions
control later conflicts. Confirmed V2 defaults include B/R inputs, SQI off,
Line A equal-files, repeated grouped 5×5, fixed10 epochs, direct 0.2–8 Hz
filtering, channel-specific OSD/PISD semantics, and manual final selection.

Device-specific QC, supervised SQI routing, motion override activation, final
artifact reducer, deployment targets and todo-only scope remain deferred. A
deferred item must remain null/disabled and cannot be filled with a convenient
placeholder.

No archived V1 artifact is current V2 evidence. Current evidence must be
generated by active V2 code and carry V2 schema, source/config/fold hashes and a
non-overwriting artifact index.
