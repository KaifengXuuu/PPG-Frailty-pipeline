# V2 specification and deferred-decision boundary

The DEV0 specification is frozen by byte hash, but explicit V2 human decisions
control later conflicts. Confirmed V2 reference defaults include B/R inputs,
SQI off, Line B equal-role-families, repeated grouped 5×5, fixed10 epochs, direct 0.2–8 Hz
filtering, channel-specific OSD/PISD semantics, and manual final selection.
These defaults are not an algorithm allowlist: ordinary V2 independently
selects implemented training, aggregation, quality, window, model and feature
modules. Line A and Line B are both executable reporting aggregations.

Device-specific QC constants, SQI/motion scientific evidence, final artifact
reducer selection, deployment targets and todo-only research scope remain
deferred. Those evidence states restrict claims and automatic winner selection;
they are not ordinary training authorization gates.

No archived V1 artifact is current V2 evidence. Current evidence must be
generated by active V2 code and carry V2 schema, source/config/fold hashes and a
non-overwriting artifact index.
