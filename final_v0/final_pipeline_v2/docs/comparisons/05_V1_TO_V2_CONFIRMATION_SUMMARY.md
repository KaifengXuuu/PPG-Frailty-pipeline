# V1-to-V2 confirmation summary

V2-018 is resolved: fixed10 default, fixed7/fixed15 named ablations.
V2-019 is resolved: convolution kernel sample counts stay fixed across the
registered DL-only resampling cases; no physical-time conversion.
V2-023 is resolved: typed OOF parquet is the lossless participant/file/window/
member exchange format and comparison input.

Other confirmed changes include:

- R1–R4 are files within R, not roles.
- Line B is the reference default; Line A/Line B reporting aggregation and
  equal-files/equal-role-families training balance are independently selectable.
- SQI defaults off; diagnostics-only is non-causal; route is an executable
  optional module whose scientific evidence remains not run.
- PTT distal mapping is pleth_1 RED and pleth_2 IR.
- ShapeFormer canonical discovery is channel-specific OSD/PISD with a derived
  PIP count and variable length bounded by three consecutive PIPs; effect-size
  fixed128/stride64 is separate.
- Final selection is human, purpose-specific and preserves ablation provenance.

The V1 transition snapshot is retained only under
`historical/v1_transition` with an immutable byte inventory.
